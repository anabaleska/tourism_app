# Чекор 1 — Јавен Git репозиториум (10%)

## Цел

Изворниот код на апликацијата да биде достапен во јавен Git репозиториум. Репозиториумот ќе ги содржи и Docker конфигурациите, CI pipeline-от и Kubernetes манифестите кои ќе се додадат во следните чекори.

## Репозиториум

https://github.com/anabaleska/tourism_app

Постојната главна гранка е `main`. При проверката таа покажува на commit `b0712da117a5d1d040a3068cf2419c89bfecf19d` (`Add logout feature and add readme`). ZIP верзијата на изворниот код одговара на оваа верзија пред локалните дополнувања за документација и `.gitignore`.

## Структура и три сервиси

| Компонента | Датотеки | Улога |
|---|---|---|
| Веб-апликација | `backend/pom.xml`, `backend/src/` | Spring Boot со Thymeleaf, автентикација и работа со туристички места |
| Препораки | `recommendation-service/app/`, `recommendation-service/requirements.txt` | FastAPI сервис за препораки |
| База | `backend/docker-compose.yaml`, `backend/src/main/resources/db/migration/` | PostgreSQL и Flyway миграции |

Thymeleaf интерфејсот е дел од Spring Boot сервисот. Третиот сервис е базата; не е потребен дополнителен front-end сервис за минималниот број од три.

## Проверка на јавната достапност

Отворете го линкот во приватен прозорец на прелистувачот без најава. Треба да се прикажуваат кодот и ознаката `Public`. Зачувајте слика од оваа страница како доказ за елаборатот.

При локалната проверка, следната команда ги врати гранките на репозиториумот без внесување GitHub корисничко име или токен:

```bash
git ls-remote https://github.com/anabaleska/tourism_app.git
```

## Работа со промени

Git чува историја на верзиите. Commit е локално зачувана група промени, а push ги испраќа commit-ите на GitHub. За нова локална копија се користи:

```bash
git clone https://github.com/anabaleska/tourism_app.git
cd tourism_app
git status
```

За објавување на дополнувањата од овој чекор, од локалната папка на проектот:

```bash
git add .gitignore docs/01-public-repository.md
git diff --cached
git commit -m "Document public repository setup"
git push origin main
```

`git diff --cached` служи за преглед на промените пред commit. За push е потребен пристап до GitHub сметката со право за запишување во репозиториумот.

## Датотеки што се исклучуваат

`.gitignore` ги исклучува генерираните build папки, Python виртуелните околини и локалните `.env` датотеки. `.env.example` може да се објави со примерни вредности. Исклучувањето со `.gitignore` не отстранува датотеки кои веќе се следат во Git.

Постојната конфигурација содржи фиксни локални database credentials. Во чекорот за Docker Compose тие ќе се заменат со конфигурација преку environment variables и примерна `.env.example` датотека. Реални лозинки и токени за регистарот не треба да се внесуваат во репозиториумот.

## Текст за елаборатот

Изворниот код на Tourism App е поставен во јавен GitHub репозиториум на адресата https://github.com/anabaleska/tourism_app. Во репозиториумот се наоѓаат Spring Boot веб-апликацијата, FastAPI сервисот за препораки и конфигурацијата за PostgreSQL базата со Flyway миграции. Главната гранка е main. Јавната достапност овозможува преглед на кодот и преземање на проектот, додека Git историјата овозможува следење на промените. Со .gitignore се исклучуваат генерирани датотеки и локални конфигурации со тајни вредности.

- Постојниот репозиториум е достапен преку Git.
- Локалната копија е поврзана со `origin` и ја користи постојната историја.
